# Phase 5 validation evidence

Evidence files in this directory are generated by local Phase 5 validation. Each record must include:

- command and working directory;
- start/end timestamps and exit code;
- exact tool version;
- redacted stdout/stderr or a path to raw redacted output;
- package or input hash;
- status `PASS`, `FAIL`, `BLOCKED` or `NOT_APPLICABLE` with a reason.

Do not place credentials, tokens, connection strings, document contents, personal data or unredacted
paths in evidence. Azure deployment, target validation, what-if and runtime cloud-test evidence do not
belong to Phase 5.

Historical runs may remain for local auditability. The frozen Phase 5 hash set includes only the
validation, container, source-security and dependency evidence referenced by its release manifest.
