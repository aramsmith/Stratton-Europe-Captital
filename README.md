# Stratton Europe Capital

Stratton Europe Capital is a synthetic architecture case study for a fictional European private-equity
firm. It demonstrates a human-centred journey from business requirements through TOGAF, Azure design,
implementation planning, deployable code, and an evidence-backed Architecture Review Board presentation.
