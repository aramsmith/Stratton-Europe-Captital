The governed demo flow

The demo separates supporting AI work from investment authority. Evidence must be admitted, analysis must be grounded and cited, human reviews are version-bound, and the final output remains a draft committee pack.

Admit evidence

Four synthetic Project Danube documents enter the governed evidence set.

Create bundle

Phase 5 authorizes an immutable, tenant-scoped analysis bundle.

Run analysis

The BFF performs supporting retrieval and model work with citation checks.

Human review

Deal, Legal, and Compliance approvals bind to the exact authoritative version.

Prepare draft

A draft-only committee pack is prepared. No investment decision is issued.

Authority boundary: the system demonstrates evidence-to-decision preparation, not automated investment approval. “Submit to committee” remains disabled.

Evidence controls

Why admission comes first

Explain that retrieval filters require the real tenant, case, admission status, and accessibility-at-review state before evidence can support analysis.

Model governance

Luna, Terra, and Sol

Show the approved route evidence: exact Azure resource, deployment, region, API version, evidence version, validity window, and fail-closed routing.

Security assurance

Twelve deterministic gates

Highlight prompt injection, citation spoofing, poisoned retrieval, cross-case access, route mismatch, silent fallback, and autonomous-authority denial.

Version governance

Current versus stale assurance

Reviews and committee evidence bind to the authoritative Phase 5 subject version. Any governed text change requires a new versioned cycle and fresh approvals.

Deployed Azure architecture

The application is deployed in Sweden Central with governed Azure OpenAI routes in West Europe. Workload communication uses managed identities, private data-plane access, and digest-pinned images.

1

Browser and identity

The public web Container App authenticates through Microsoft Entra and acquires delegated BFF access without storing a secret.

2

Governed BFF

The BFF enforces delegated authorization, scenario policy, tenant/case boundaries, citations, review currentness, and committee-preparation rules.

3

Phase 5 authority

The private Phase 5 API authorizes immutable analysis bundles and validates signed BFF workload tokens before accepting completion.

4

Private data plane

Azure SQL, Blob Storage, Service Bus, and Search use managed identity and private network paths; Search evidence is bounded for model quota safety.

5

Governed AI routes

Luna, Terra, and Sol bind to approved Azure OpenAI deployments using API version 2025-04-01-preview, explicit output limits, and route evidence.
