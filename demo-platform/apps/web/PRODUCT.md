# Product

## Platform

web

## Users

Investment professionals, deal leads, specialist reviewers, governance stakeholders, and internal
assurance users evaluating Project Danube in a controlled private-equity workflow.

## Product Purpose

The Stratton demo platform demonstrates a governed evidence-to-decision process: admit evidence,
run grounded and cited analysis, record human dispositions and specialist reviews, prepare a draft
committee pack, and expose lineage and audit readiness without automating investment authority.

## Positioning

The product binds evidence, model routes, findings, human approvals, security gates, and committee
preparation to authoritative versions so assurance is current, inspectable, and fail-closed.

## Operating Context

Users work across three connected workspaces: AI Deal Workbench, Governance & Assurance Console,
and Investment Decision Room. The primary scenario is the synthetic Project Danube private-equity
opportunity. The application is used as a live Azure demonstration and as an operating interface for
reviewing evidence, findings, approvals, security gates, lineage, and audit-export readiness.

## Capabilities and Constraints

- Microsoft Entra authentication and delegated API access are required in the deployed environment.
- Evidence, analysis bundles, findings, reviews, security evidence, and recommendation preparation
  preserve governance and version boundaries.
- Committee submission remains disabled and human-only.
- The BFF demo projection is currently process-local and must remain at one replica.
- Existing workflow semantics, labels, accessibility, and testable user actions must remain intact.
- The interface must remain responsive and usable on common desktop and tablet widths.
